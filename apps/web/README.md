# apps/web

Application web Next.js (public + espace utilisateur + backoffice admin).

## Arborescence suggérée
- `src/app/(public)` home, explorer, campaign
- `src/app/(auth)` login/register/forgot/reset
- `src/app/(dashboard)` campagnes, dons, retraits, profil
- `src/app/(admin)` modération, signalements, paramètres
- `src/components` CampaignCard, ProgressBar, DonationModal, UpdateTimeline, VerificationBadge
